### Quick Summary

1. **Mission**: Become the standard architecture discovery and observability governance platform for agentic AI systems.
2. **Core Positioning**: *"Shift-Left for AI Agents"* — reconstruct deterministic topology, detect observability blind spots, and enforce quality gates in CI/CD before production deployment.
3. **Product-Led Growth (PLG)**:
   - Free, zero-overhead open-source CLI (`cz scan`, `cz view`, `cz init`).
   - Viral GitHub Action posting visual Mermaid flowcharts and telemetry audits directly on PRs.
   - Privacy-first local always-on runtime capture with automatic secret redaction.
4. **Monetization**:
   - **Open Source (Free)**: Core static scanner, local visualizer, single-repo CI gate.
   - **Cohzen Team (Cloud)**: Multi-repo architecture registry, PR architecture drift diffs, team dashboards.
   - **Cohzen Enterprise (On-Prem/Private Cloud)**: Custom policy engine, SOC2/compliance reports, SSO, SLA.
